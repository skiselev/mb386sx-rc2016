# Alsea River 386SX Motherboard - User Guide

## Specifications

* Processor support: Intel 80386SX, AMD Am386SX/SXL, Cyrix Cx486SLC, TI Tx486SLC, TI TI486SXLC, and other processors pin compatible with Intel 80386SX.
* Math coprocessor support: Intel 80387SX or compatibles.
* Memory: From 512 KiB to 16 MiB of RAM, using 2 or 4 30 pin SIMM modules, from 256 KiB to 4 MiB each.
* System BIOS: 128 KiB flash ROM, that can be programmed in-system.
* 6 ISA slots.
* PS/2 keyboard and PS/2 mouse support.
* Real Time Clock (RTC) and battery backed non-volatile RAM (NVRAM), using replaceable CR2032 battery for backup.
* 20-pin ATX power connector.
* On-board diagnostic LEDs, and power and reset switches.

## Jumpers and Headers

### JP1 - Clear CMOS/NVRAM

Position | Description
---------|------------
Open     | Normal operation
Closed   | Clear CMOS/NVRAM

### JP2 - Select Display Type

Position | Description
---------|------------
Open     | Monochrome
Closed   | Color

Note: This jumper is applicable to the CGA and MDA display controllers.
VGA display controllers typically can detect the display type automatically, and the setting of this jumper has no effect on the VGA display type selection.

### JP3 - Keyboard Lock

Position | Description
---------|------------
Open     | Normal operation, keyboard unlocked
Closed   | Keyboard locked

### JP4 - CPU Clock Select

Position | Description
---------|------------
1-2      | 40 MHz
2-3      | 33 MHz or below

Note: Setting to 1-2 (40 MHz), effectively disables address pipelining, leading to a slightly slower performance. All 40 MHz CPUs tested so far work well with the 2-3 setting.

### JP5 - FPU Clock Select

Position | Description
---------|------------
1-2      | Synchronous operation. The FPU uses the same clock as the CPU, generated by the oscillator X1
2-3      | Asynchronous operation. The FPU uses the clock generated by the oscillator X2

### JP6 - IRQ12 Source Select

Position | Description
---------|------------
1-2      | IRQ12 is connected to the keyboard/mouse controller and used for PS/2 mouse
2-3      | IRQ12 is connected to the ISA bus

Note: Set the JP6 to the position 1-2 when using a PS/2 mouse

### J13 - Front Panel Header

Pin | Description                 | Pin | Description
----|-----------------------------|-----|------------
1   | Speaker (-) terminal        | 2   | Turbo switch input
3   | Not connected               | 4   | GND, Turbo switch
5   | GND                         | 6   | Not connected
7   | 5V, Speaker (+) terminal    | 8   | Power LED (+) terminal
9   | Turbo LED (+) terminal      | 10  | Power LED (+) terminal
11  | GND, Turbo LED (-) terminal | 12  | GND, Power LED (-) terminal
13  | Reset switch input          | 14  | Power switch input
15  | GND, Reset switch           | 16  | GND, Power switch

## Memory Configuration

The motherboard has two memory banks:
* Bank 0 are the two SIMMs closer to the edge of the board.
* Bank 1 are the two SIMMs closer to the chipset.

A memory bank, if used, must be fully populated. That is, both SIMMs should be installed.
Bank 0 must be populated first, before populating Bank 1.
All SIMMs must be the same size.
The motherboard supports fast page mode (FPM) DRAM memory. Recommended memory latency 60-70ns.

### Supported Memory Configurations

Bank 0 (J1, J2) | Bank 1 (J3, J3) | Memory Size
----------------|-----------------|------------
256 KiB x 2     | None            | 512 KiB
256 KiB x 2     | 256 KiB x 2     | 1 MiB
512 KiB x 2     | None            | 1 KiB
512 KiB x 2     | 512 KiB x 2     | 2 MiB
1 MiB x 2       | None            | 2 MiB
1 MiB x 2       | 1 MiB x 2       | 4 MiB
4 MiB x 2       | None            | 8 MiB
4 MiB x 2       | 4 MiB x 2       | 16 MiB

## PS/2 Mouse Support

The PS/2 connector on Alsea River 386SX Motherboard contains PS/2 keyboard and PS/2 mouse signals. A PS/2 Y splitter cable should be used to connect both a keyboard and a mouse.
Note that with most Y splitter cables, the keyboard should be connected to the mouse connector, and the mouse should be connected to the keyboard connector. Refer to the table below for the splitter cable pinout.

### PS/2 Combo Port Pinout

Pin - Motherboard | Pin - Keyboard | Pin Mouse | Signal Description
------------------|----------------|-----------|-------------------
1                 | 1              | -         | Keyboard data
2                 | -              | 1         | Mouse data
3                 | 3              | 3         | GND, Ground
4                 | 4              | 4         | VCC, 5V
5                 | 5              | -         | Keyboard clock
6                 | -              | 5         | Mouse clock
